# To-Do App

Минималистичное приложение со списком задач, создаваемое как учебный проект с потенциалом для роста.

## Возможности

- Добавление задач с названием и датой выполнения (по умолчанию — сегодня)
- Отметка задач как выполненных / не выполненных
- Задачи разбиты на два раздела: **Сегодня** и **Просрочено**
- Просроченные задачи выделяются красным
- Данные сохраняются в **LocalStorage** — не пропадают при перезагрузке страницы

## Стек

- React 18 (через CDN, без сборки)
- Babel Standalone (JSX-трансформация прямо в браузере)
- Чистый CSS
- LocalStorage

## Быстрый старт

Установка не нужна. Просто откройте `index.html` в браузере.

```bash
git clone https://github.com/CodeMeager/todo-app.git
cd todo-app
open index.html   # macOS
# или дважды кликните index.html на Windows
```
